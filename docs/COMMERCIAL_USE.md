# 商业使用与许可边界

## 当前生效许可

本仓库目前依据根目录 [LICENSE](../LICENSE) 的 **AGPL-3.0-only** 发布。本说明没有增设“禁止商用”限制，也不替代完整条款。

AGPL 允许商用。分发覆盖程序时须履行相应许可、声明与对应源码义务；修改后的版本通过网络与用户交互时，第 13 条要求向这些用户显著提供获取对应源码的机会。不是所有商业行为都触发完全相同的义务，不能把 AGPL 简化为“商用必须获得作者额外许可”。

## 希望禁止未经许可的商用时

作者可在拥有相应权利的前提下，为后续版本选择单独的非商业许可，并提供书面商业授权渠道。这种模式应称为“源码可见、非商业使用”，不应继续宣称符合 OSI 的开源定义。需要先确定商用范围、教育与研究例外、授权联系人、贡献权利以及第三方内容范围，再同步更新 LICENSE、包元数据、文档与发布检查。

**这一调整尚未生效。** 不能只在 README 追加一句“禁止商用”，同时保留冲突的 AGPL 授权。

已按 AGPL 获得的既有授权不能因新版本换协议而被追溯撤回。在遵守原许可的情况下，旧版本仍可继续使用、修改和再分发。第三方依赖和外部贡献的许可也不能单方面替换。商业限制不会保证无人复制；静态水印只辅助识别来源。
