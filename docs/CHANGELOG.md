# 变更记录

## 0.2.1 媒体更新

- 8 张展示截图全部重新采集，替换当前分支旧版素材；新增手机任务卡和导诊单展示。
- 24 秒截图导览视频全部使用新版画面重新制作，包含桌面和手机界面。

## 0.2.1

- 统一默认院区总览，取消手机启动时的自动相机移动。
- 建筑名称支持双击 / 手机双点进入，键盘回车可直接触发；确认反馈和镜头过渡更克制，尊重减少动态效果设置。
- 手机工具栏、状态卡可收起 / 展开；面板位移、箭头和地图尺寸连续过渡。
- 修正三维画布重复扣减高度、初始化零尺寸以及深色主题图标对比问题。
- 增加原子的 skip-wait 演示操作，仅在到达诊室且处于候诊阶段生效，不自动接诊；补充状态机回归测试。
- 修正 Vinext 局域网参数为 --hostname，电脑和手机可访问同一演示服务。
- 补齐历史手机截图归档、演示说明与源码清单。图片及截图导览视频记录 0.1.0，尚未重新录制最新版连续操作视频。
